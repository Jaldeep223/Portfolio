# Portfolio Website

A personal portfolio website built with **React** and **Tailwind CSS** showcasing my projects, skills, and contact information.  
It features **light and dark mode** support, fully functional **social media icons**, and a **contact form**.

---

## Demo

Live site: [https://Jaldeep223.github.io/Portfolio](https://Jaldeep223.github.io/Portfolio)

---

## Features

- **React** for component-based UI development  
- **Tailwind CSS** for utility-first styling and responsive design  
- **Light and Dark mode** toggle for better user experience  
- Fully functional **Contact Form** to get in touch  
- Social media icons linking to my profiles (GitHub, LinkedIn, Twitter, etc.)  
- Showcases my projects with images and descriptions  

---

## Technologies Used

- React  
- Tailwind CSS  
- Vite (for build tooling)  
- React Icons (for social media icons)
